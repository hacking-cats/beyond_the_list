# public/brand

PostFinance brand files supplied by the team for the PostFinance challenge demo (see the exception in `docs/design/design-system/foundations/brand.md`).

| File | Size | Use |
|---|---|---|
| `postfinance-mark.png` | 447 × 447 | Square mark (yellow background, petrol cross): source of every favicon and app icon |
| `postfinance-logo.png` | 2400 × 694 | Full logo, mark + wordmark on yellow |
| `postfinance-logo-600.png` | 600 × 174 | Same logo, light enough for a screen |

Generated from the mark: `public/favicon.ico` (16, 32, 48), `public/icons/favicon-{16,32,96,128}.png`, `apple-icon-180x180.png`, `icon-192x192.png`, `icon-512x512.png` (for Android / PWA later). The 16 and 32 px sizes crop the yellow margin so the cross stays readable.
