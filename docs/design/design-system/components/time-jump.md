# Time jump

The demo moves from 23 September to 23 December 2025 (decisions D2, B6).

## Trigger
- Ghost button in the header, jump icon and "Jump ahead". Visible only in demo mode.

## Screen
- Full-screen petrol background, white text, centred.
- Line 1 (display): "23 December 2025". Line 2 (subtitle): "Three months later".
- Shows for 1.5 s, or until tapped, then fades to the statement of 23 December (loaded from `facts_2025-12-23.json`).
- With reduced motion: no fade, instant switch.
- The header date changes to "Today: 23 December 2025".
