# Button

| Variant | Look | Use |
|---|---|---|
| Primary | Yellow background, text.primary label | The one main action on a screen, e.g. "Yes, these are mine" |
| Secondary | White background, 1px petrol border, petrol label | The alternative, e.g. "Check with my bank" |
| Ghost | Petrol label, no border | Close, "Jump ahead" |

- Minimum height 48px, radius md, label 16px weight 600.
- States: pressed (yellowDark or petrolDark), focus (2px petrol outline, 2px offset), disabled (text.disabled).
- Labels are verbs.
