# Lovable instructions (optional: sketches only)

Not needed to build the app. Use only if someone wants to sketch screens first.

Lovable is used to sketch screens so the team can agree on the look. Its code does not go into the app (B4).

Sketch exactly these screens, mobile width 360px, with the tokens in `tokens/color.json` and the components in `components/`:

1. Statement of 23 September 2025: header with "Today: 23 September 2025" and a "Prototype · demo data" chip, lines grouped by day, some with the lightbulb marker.
2. Answer sheet, normal tone: card payment 10'018.53 CHF.
3. Answer sheet, action tone: four identical airline charges of 1'766.50 CHF, with the two buttons.
4. Time-jump screen: "23 December 2025 · Three months later".

Rules: one typeface (Inter), yellow only as primary button background, grapefruit only for the action tone border and icon, navigation only through the bottom tab bar with icons (no hamburger menu), no bank names or logos. Use the texts from `review_2025-09-23.md`; do not invent explanations.
