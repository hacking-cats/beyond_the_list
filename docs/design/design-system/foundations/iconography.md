# Icons

- One outline icon family, 24px default, 20px in list lines.
- Icons support meaning and always come with text or an accessible label.
- Fixed meanings, one shape each:
  - lightbulb: worth a look (petrol)
  - triangle with exclamation mark: attention (warningText)
  - octagon with exclamation mark: action needed (grapefruit)
  - info circle: worth knowing (infoText)
  - arrow-right-circle: time jump (petrol)
