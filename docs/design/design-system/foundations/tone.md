# Tone of voice

All texts come from `facts.json`, built from `content.json`. The UI never writes or rewrites explanations, and never removes the wit line.

Rules live in `product_decisions.md` (T1–T4) and `content.json` (`wit_rule`). In short:

- Short sentences, plain words, the Swiss term first: "Halbtax is…".
- Three tones: normal (light wit allowed), attention (neutral), action needed (serious, one clear action).
- Wit gently points at a money habit worth reconsidering; no habit, no wit. Never about the person, never on essentials.
- Microcopy written by us (buttons, headings) follows the same rules: clear verbs, no jargon, no blame.

Fixed microcopy:

| Where | Text |
|---|---|
| Sheet headings | What it is · Your picture · Worth knowing |
| Marker label | Worth a look |
| Attention heading | Worth a check |
| Action buttons | Yes, these are mine · Check with my bank |
| Question input | Ask about this line |
| Live answer loading | Looking at your lines… |
| Live answer error | Couldn't reach the assistant. Here is what your statement shows. |
| Time jump | 23 December 2025 · Three months later |
