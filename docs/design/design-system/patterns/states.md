# States

The statement is local data, so it has no loading or empty state.

| Where | Loading | Error |
|---|---|---|
| Suggested question | none, answer is precomputed | none |
| Typed question | "Looking at your lines…" | "Couldn't reach the assistant. Here is what your statement shows." plus the picture |
| Action buttons | none | none: the result is a local confirmation |

If the network is down, everything except typed questions still works (A4).
